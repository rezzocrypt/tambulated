# Правила проекта

## Changelog и версионирование

- Ведите `CHANGELOG.md` в формате [Keep a Changelog](https://keepachangelog.com/). Незаверсионированные правки складывайте в раздел `[Unreleased]`.
- После каждой заметной пользовательской правки (новая функция, изменение UI, исправление бага) добавляйте запись в `CHANGELOG.md` — в раздел для текущей версии, а при его отсутствии — в `[Unreleased]`.
- Поднимайте версию в `package.json`:
  - **patch** — исправления и мелкие правки;
  - **minor** — новые функции и заметные изменения UI;
  - **major** — обратно несовместимые изменения.
- При поднятии версии перенесите записи из `[Unreleased]` в новый раздел `[x.y.z] — ГГГГ-ММ-ДД`, проставьте версию в `package.json` и проверьте, что собранное приложение (настройки) показывает её корректно.
- Записи краткие, на русском языке, сгруппированы по подразделам `Добавлено` / `Изменено` / `Исправлено`.
- Ничего не коммитьте без явной просьбы пользователя.
